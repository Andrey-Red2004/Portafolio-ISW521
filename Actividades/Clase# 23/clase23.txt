actividad:3 Qué es cada componenteSmart (Contenedor): Maneja el estado, los efectos (fetch) y la lógica. No suele tener estilos propios.Dumb (Presentacional): Solo recibe datos por props y los pinta. No sabe de dónde viene la información. Es altamente reutilizable.

Smart (Contenedor): Maneja el estado, los efectos (fetch) y la lógica. No suele tener estilos propios.Dumb (Presentacional): Solo recibe datos por props y los pinta. No sabe de dónde viene la información. Es altamente reutilizable.

 
import { useState, useEffect } from 'react';
import WeatherCard from './WeatherCard';

export default function WeatherContainer({ ciudad }) {
  const [clima, setClima] = useState(null);
  const [error, setError] = useState(false);

  useEffect(() => {
    fetch(`https://weather.com{ciudad}`)
      .then(res => res.json())
      .then(data => setClima(data))
      .catch(() => setError(true));
  }, [ciudad]);

  if (error) return <p>Error al cargar</p>;
  if (!clima) return <p>Cargando...</p>;

  // Pasa los datos limpios al componente dumb
  return <WeatherCard temperatura={clima.temp} condicion={clima.text} ciudad={ciudad} />;
}
