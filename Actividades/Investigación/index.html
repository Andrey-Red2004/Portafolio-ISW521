Collapse (Acordeón)

Sistema de 12 columnas: Divide el ancho disponible en 12 partes iguales. Usas .col-* para especificar cuántas columnas ocupa cada elemento. .col-lg-6 = 6 de 12 = 50%. El grid es completamente fluido y responsivo.

Puntos de quiebre: Tamaños de pantalla donde Bootstrap cambia estilos automáticamente. Principales: xs (<576px), sm (≥576px), md (≥768px), lg (≥992px), xl (≥1200px). Usas .col-md-6 .col-lg-3 para aplicar estilos distintos según el breakpoint.

Clases de un solo propósito: .m-3 = margin 1rem, .p-2 = padding 0.5rem, .text-primary = color primario, .bg-success = fondo verde, .d-flex = display flex. Bootstrap proporciona cientos de utilidades para aplicar estilos sin escribir CSS.
Tabs (Pestañas)
Bootstrap proporciona componentes listos: Button, Card, Modal, Toast, Navbar, Form, Table, Badge, Alert, Collapse, Tabs, Dropdown, y más.
Variables CSS: Personaliza colores y tamaños modificando variables en :root. --bs-primary: #2563eb;. Sin !important necesario. Bootstrap respeta la especificidad CSS nativa.

¿Cómo funciona?
