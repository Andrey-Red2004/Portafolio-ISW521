Bootstrap es un framework CSS que proporciona componentes y utilities preestilos para construir sitios responsive rápidamente.

Los breakpoints son anchos de pantalla predefinidos (xs, sm, md, lg, xl, xxl) en los que el diseño cambia para adaptarse a dispositivos de diferentes tamaños.

El grid system divide la pantalla en 12 columnas. Las clases como col-lg-3, col-md-6 especifican cuántas columnas ocupar en cada breakpoint.
